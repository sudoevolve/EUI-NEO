# 科学绘图：三维与体数据

`eui::module_plot` 的 `Plot3D` 是可交互三维视口。原始坐标、相机及 CPU 参考计算使用
`double`。交互使用 OpenGL 3.3 片元着色器遍历 BVH、逐射线合成透明交点，并在交点之间积分体数据。
GPU 坐标在 double 中先减场景原点、缩放，再转换 float；源数据不被改写。

GPU 输出 RGBA8 颜色和 R32F 深度，普通 UI 合成颜色纹理。相机变化只更新 uniform，尺寸/DPI
变化只更换输出纹理，不重建 BVH 或上传几何。静置不重绘；标注深度只在重绘时读取，标签结果缓存。
CPU `SceneRenderer3D` 保留双精度参考求交、拾取和离线导出。GPU 浮点边缘、共面去重及纹理插值
与 CPU 可能有少量像素差异，不承诺逐字节一致。Vulkan 仅可使用不依赖窗口的数值与
导出接口，`Plot3D::compose()` 的 Vulkan 纹理上传明确报错。
本模块复用已有 libpng、FreeType，不增加重依赖。可通过 `EUI_ENABLE_PLOT=OFF` 关闭。

## 最小三维视口

```cpp
#include "modules/plot/plot3d.h"

using namespace modules::plot;
Plot3D plot;

void initializePlot() {
    auto curve = std::make_shared<Geometry3D>(
        curve3D({-1, 0, 1}, {0, 1, 0}, {-0.5, 0, 0.5}));
    Scene3D scene;
    scene.bounds = {{-1.2, -0.2, -1}, {1.2, 1.2, 1}};
    scene.objects.push_back({curve, Material3D{}, true});
    plot.setScene(scene);
    plot.resetView();
}

void compose(eui::Ui& ui) {
    plot.compose(ui, "space", 640, 480, 1.0);
}
// 窗口设备销毁前：plot.releaseGpu(); 然后销毁 plot。
```

`setScene()` 不隐式改变相机；新数据需要重新拟合时调用 `resetView()`。
`Scene3D::bounds` 为有限、严格递增的世界坐标范围，默认作为裁剪盒，并生成 XYZ 线性刻度与
边界框。关闭 `showAxes` 隐藏框与刻度，关闭 `clipToBounds` 允许几何超出数据盒。
相机的 near/far 裁剪始终生效。XYZ 当前使用世界空间线性轴，不支持三维对数轴。

鼠标操作：左键拖动轨道旋转，Shift 拖动平移，滚轮缩放，右键拟合复位，点击选择，
两次 Ctrl 点击测距。`setEnabled(false)` 取消正在进行的拖动。Runtime 负责指针捕获，
移出后释放及交互中重组有测试；1×/2× DPI 使用相同逻辑位移。正交/透视通过
`ViewState3D::camera.projection` 切换。相机旋转角度为弧度，FOV 为垂直视场角（度）。
滚轮以相机目标为中心改变视野，不以鼠标所在深度为缩放中心。

## 几何、样式与拾取

| 接口 | 输入与行为 |
| --- | --- |
| `curve3D(x,y,z,false)` | 独立等长 XYZ 数组，顺序相邻点连线；NaN/Inf 端点令线段缺失 |
| `curve3D(x,y,z,true)` | 世界空间球形散点，保留原始点下标 |
| `surface3D(RectilinearField,false)` | 行优先 Z 高度、显式单调 X/Y 网格；每个单元固定对角线拆成两个三角形 |
| `surface3D(field,true)` | 网格横纵边线框，不额外绘制单元对角线 |
| `Geometry3D` | 任意索引三角网格、线段或点；越界索引和属性长度不一致抛异常 |
| `computeNormals()` | 面积加权顶点法线；退化面不产生可拾取表面 |
| `contourProjection3D()` | 复用二维 marching squares，将指定等值线投影到固定 Z 平面 |

`Geometry3D` 的 positions、normals、scalars、colors、sourceIndices 各自独立。
可选属性为空时使用默认样式；非空时长度必须与 positions 一致。三角形中任意坐标缺失则
跳过整面；标量缺失使用色阶的 missingColor，不改成零。颜色为 straight RGBA。

`Material3D` 提供基色/透明度、顶点颜色、标量色图、法线、双面 Lambert 方向光、ambient、
背面剔除及世界空间 radius。线为圆头胶囊，点为球，半径不以 UI 像素为单位。
材质基色与顶点/标量颜色相乘；想保留色图原色应将基色设为 `{1,1,1,1}`。
`SceneRenderer3D` 使用对象各自色阶；`Plot3D` 对启用 scalarColors 的对象应用
`ViewState3D::colorScale`，便于统一保存与恢复。

`SceneRenderer3D::pick()` 返回最近可见几何表面的位置、法线、object、primitive、
重心权重与 sourceIndex。sourceIndex 是权重最大的源顶点索引；**交点位置是插值位置**，
不冒充原始采样点。生成网格可填写 sourceIndices 将结果映射回源数组；等值面映射到
生成边上更近的原始 voxel。测距是世界坐标欧氏距离，异单位轴的物理解释由应用负责。
直接体积分没有唯一表面，因此不参与几何拾取；应使用切片或等值面选择体数据位置。
透明几何的选择取最近非零透明度表面，不穿透到后面对象。

标注锚点使用相机投影与首个非零覆盖样本的深度进行可见性检查。被遮挡的锚点不显示；
文字作为普通 UI/导出文本整体显示，不做逐字形深度切割。轴刻度属于叠加说明，不随数据遮挡隐藏。

## 体数据、切片及等值面

`VolumeLayout` 明确 `dimensions={nx,ny,nz}`、正的 `spacing={dx,dy,dz}` 与 origin。
每轴至少两个网格点，索引 `(x,y,z)` 的位置为 `origin + spacing*(x,y,z)`。
布局固定为 Float64、X 最快、`(z*ny+y)*nx+x`，没有隐式字节序转换或坐标轴翻转。
维度乘积溢出、无效 spacing、非有限范围和错误存储长度都会抛异常。

```cpp
#include "modules/plot/volume.h"

VolumeLayout layout{{128,128,128}, {0.5,0.5,1.0}, {-32,-32,0}};
auto values = std::make_shared<const std::vector<double>>(layout.sampleCount(), 1.0);
auto volume = std::make_shared<VolumeData>(layout, values); // 共享数组，不复制
SliceLink cursor(layout);
cursor.setPosition({0,0,60});
auto axial = volumeSlice(*volume, cursor.plane(2));
auto iso = isoSurface(*volume, 0.5, 32*1024*1024);
```

`sample(world)` 做三线性插值；越界或有非零权重的缺失样本返回 nullopt。
恰好位于网格点时不会因零权重邻点的 NaN 变成缺失。`gradient()` 使用半步中心差分，边界改用
单边差分；缺失方向分量为零。NaN/Inf 均为缺失数据。

`SlicePlane` 的 origin 为输出左下网格点，u/v 为正交方向（内部归一化），width/height 为世界
长度，columns/rows 为网格点数。输出是带原始标量、法线和源索引的三角网格；越界/缺失点
不会生成有效表面。`SliceLink` 保存共享世界位置，夹到体范围内；位置实际变化才递增 revision。
`plane(0/1/2)` 分别产生法向沿 X/Y/Z 的平面。应用读取同一 cursor 重建多个视图，不发送递归联动
事件。任意斜切面直接填写 `SlicePlane`。

等值面使用一致的六四面体立方单元拆分，内部按四面体线性插值；它与体绘制的三线性重建不同，
曲场的两者结果会有网格尺度误差。相邻单元使用一致的面/体对角线，共享交边顶点；恰好落到网格
顶点时使用统一顶点键。法线朝标量增大的方向，三角形绕序与此一致；高斯场法线因此朝内部。
包含缺失值的整个立方单元跳过，数据边界不封口，等值面可有边界。恒等于 isovalue 的平坦体积
不定义唯一曲面，采用严格 `< level` / `>= level` 分类，不输出该平坦体积内部的面。
提取预算涵盖几何容量与交边表的记账空间，超出抛 `length_error`，不输出截断网格。

## 按需缓存与体合成

另一种 `VolumeData` 构造接受 Loader、cacheBytes 和 brickEdge：

```cpp
auto streamed = std::make_shared<VolumeData>(layout,
    [](const VolumeBrick& brick, std::vector<double>& out) {
        // 从文件或已完成的计算结果填写这一块；out 已按 brick.size 分配。
        // 块内同样按 X 最快排列，末端块可能小于 brickEdge。
        loadCompletedBrick(brick.first, brick.size, out);
    }, 16*1024*1024, 16);
```

LRU 在下一次装入前淘汰最久未使用块。预算必须至少容纳最大单块及记账开销；加载回调不得改变
out 长度，也不得偷偷保留或修改借出的数组。跨块插值每次读取数值，不持有可能被淘汰的地址。
`invalidate(region)` 仅淘汰重叠块并增加 revision；Plot3D 在下次 compose 按新数据重绘。
更新发生时生成的切片/等值面快照不会自动改变，应用应重新生成。`clearCache()` 显式回收缓存，
空闲时保留预算内的热块。dense 数组由调用方管理，不能通过 invalidate 修改共享 const 数据。

`VolumeLayer` 包含数据、`TransferFunction` 和 referenceStep。传递函数的有限标量节点严格
递增，RGBA 线性插值，范围外夹到端点，非有限输入全透明。
体积分按 `RenderSettings3D::volumeStep` 的世界步长取区间中点；referenceStep 是传递函数 alpha
对应的参考距离，实际 alpha 为 `1-(1-alpha)^(step/referenceStep)`。常量体的透明度因此不会
随着质量设置改变。没有随机采样、早停阈值、散射、多次反射或体光照。

每条射线收集几何交点并按距离排序，在相邻交点之间积分体数据，再合成表面。因此相交透明几何
及一个体数据层可正确交错；不使用整对象中心排序。同一对象共边上重合的交点去重，等深不同对象
按场景顺序打破平局；共面重叠无法定义独立的物理先后关系。点/胶囊作为一次表面覆盖，三角闭合
物体的前后面作为两个表面。体积分精度受网格重建与步长影响，不宣称连续积分的解析精确值。
CPU 每条射线超过 maxFragmentsPerRay 或 maxStepsPerRay 明确报容量错误，不悄悄丢层。
GPU 依次寻找最近交点，不分配交点列表，也不受 CPU 的 maxFragmentsPerRay 列表容量限制；
迭代上限来自场景图元总数。体采样的保守上界超 maxStepsPerRay 时回退 CPU，再按实际射线检查。

## 预算、生命周期与线程

默认 `RenderSettings3D`：workingBytes 为 128 MiB，每射线最多 4096 个几何交点、100000 个体样本，
volumeStep 为 0.04。workingBytes 保守计入引用的几何容量、BVH、单射线交点缓冲及一帧 RGBA8/depth。
不覆盖应用持有的数据、额外渲染结果、字体系统、分配器元数据及窗口框架缓存，不是进程总内存上限。
渲染失败不更换视口中已有纹理。更新过程中旧帧与新帧可短暂并存。

GPU 的 `Budget::vertexBytes` 默认 64 MiB，覆盖打包后的 BVH、图元与 RG32F 体纹理。
体数据按 Z 平面暂存上传，源和 revision 不变时复用；更新 revision 后重传该体纹理。
大型按需源的切片仅上传生成的网格，不装入整个体。直接体绘制超预算或 GL 3D 纹理尺寸限制时
回退 CPU；极深缩放下相机 float 舍入接近像素间距也回退 CPU，因此这些超范围场景仍可能较慢。
GPU 体标量按传递函数范围归一化；缺失值通过有效权重通道跳过（float 容差 1e-6）。
`Budget::textureBytes` 默认 64 MiB，计入 RGBA8 + R32F（每像素 8 字节），超预算或
超过 GL 最大纹理尺寸会拒绝分配。同尺寸内容更新复用纹理。旧 UI 图像由核心外部图像机制保留到 GPU
使用完成；新尺寸替换时旧纹理可能短暂并存。`releaseGpu()` 释放模块图像及 CPU 显示帧；对象析构
释放场景、BVH、交互状态；其他对象共享的数据仍然有效。

所有视口操作、Loader、缓存更新在所属 UI 线程执行。后台计算可生成新的只读几何或 dense 数组，
完成后投递到 UI 线程应用。发布后不可经其他别名修改数组。数值渲染可在独立线程使用独占的
SceneRenderer3D/VolumeData，但不能与 UI 同时访问同一可变缓存。回调 weak_ptr 不延长 Plot3D 生命周期。
静态视图没有定时器和 ImageStream，数据、相机、尺寸、DPI 或 volume revision 变化才重绘。

## 导出与视图复现

```cpp
auto output = plot.exportScene(2400, 1800, 2.0); // 重新投影渲染；文本尺寸倍率为 2
writeSvg(output, "figure.svg");
writePdf(output, "figure.pdf");
writeRasterPng(output, "figure.png", "assets/JingNanJunJunTi-JinNanJunJunTi-Bold-2.ttf", 192);
const auto saved = saveView3D(plot.view());
plot.setView(restoreView3D(saved));
```

导出不截取窗口。几何和体像素在指定尺寸重新计算，轴与标注按新投影定位。
SVG 中三维内容是 data URI PNG；PDF 使用 RGB image XObject 与灰度 soft mask，均保留文本层。
SVG 字体由查看器决定；PDF 当前 Helvetica 不嵌入字体，仅保证基本 Latin 文本，不支持完整 Unicode
字体嵌入。含中文等文字优先使用指定字体的 PNG 或由有相应字体的 SVG 查看器呈现。
PNG 基于 FreeType 栅格化 UTF-8 普通文本，缺字依次尝试 U+FFFD、问号和字体的缺字字形，不做复杂
文字 shaping 或公式排版。writeRasterPng 只接收 raster/text，遇到 path 会报错，避免遗漏内容。
PNG 的 dpi 参数写入物理像素密度元数据，不改变指定像素尺寸；文本倍率由 exportScene 独立指定。

`saveView3D()` 的版本化文本保存相机、色图/线性或对数色阶/范围/自动标志/缺失颜色、标注；
restore 校验全部内容并拒绝尾随垃圾。复现要求使用相同数据快照、场景边界、材质、体传递函数和
RenderSettings3D；文件不序列化数据源、Loader、GPU、字体或任意回调。原始数据不会被显示或导出
降采样覆盖。错误状态恢复不会替换已经工作的视图。

## 示例与验证

集成示例为 `scientific_plot_phase3`（3×2 面板）和 `scientific_plot_phase4`（4×2 面板），
沿用二维集成示例的同页展示方式。第三阶段包含 XYZ 曲线/散点、NaN 断线、曲面/等高线投影、
线框/法线、带顶点颜色的任意网格、光照/剔除、相交透明面、裁剪/深度标注、拾取/测距；
可切换投影、输入、DPI，或销毁重建全部视口。
第四阶段包含三轴联动切片、任意斜切片、等值面/缺失区域、体传递函数/质量、体与透明几何合成、
512³ 按需数据源/缓存/预算错误展示。工具栏可更新数据、释放缓存，保存恢复全部相机、色阶、标注、
切片位置、等值、传递函数预设及采样质量。两个示例均支持整页 PNG/SVG/PDF 高分辨率导出。
各面板独立保存相机，局部按钮不重置其他面板的视角、选择或测距。第三阶段的色阶与法线
分别只更新曲面与线框面板；第四阶段的 Angle、Isovalue、Quality、Transfer 只作用于所在面板。
两个体绘制面板分别保存采样质量和传递函数；合成面板的外壳固定使用 0.3 等值。
Move X/Y/Z 与 Link pick 明确共享切片位置，仅重建位置实际改变的切片及相关合成视图；
它们不改变相机。缺失区域开关位于顶部，标为 Missing data (all)，修改七个小体数据视图
共用的数据源。保存状态包含两套体绘制设置，也兼容旧文件中的一套共享设置。
原先的三维、切片、等值面、体绘制独立小例子已合并删除。
输出文件写到进程工作目录；PNG 示例需工作目录含已复制的 assets。

```powershell
cmake -S . -B build -DEUI_BUILD_TEST_FIXTURES=ON
cmake --build build --target plot_spatial plot_export plot_spatial_runtime_probe plot_spatial_benchmark plot_gallery_phase3_probe plot_gallery_phase4_probe scientific_plot_phase3 scientific_plot_phase4 --parallel
ctest --test-dir build -R "plot_(spatial|export)" --output-on-failure

cmake -S . -B build-sdl2 -DEUI_WINDOW_BACKEND=sdl2 -DEUI_RENDER_BACKEND=opengl -DEUI_BUILD_TEST_FIXTURES=ON
cmake --build build-sdl2 --target plot_spatial plot_export plot_spatial_runtime_probe plot_spatial_benchmark plot_gallery_phase3_probe plot_gallery_phase4_probe scientific_plot_phase3 scientific_plot_phase4 --parallel
ctest --test-dir build-sdl2 -R "plot_(spatial|export)" --output-on-failure
```

数值测试检查相机往返/大偏移、XYZ 缺口、三角/线/点、深度与裁剪/剔除、交叉透明排序、拾取索引、
标注遮挡、切片位置、等值面闭合球拓扑与仿射场等值、NaN 单元、传递函数和解析常量体透明度。
窗口 probe 通过实际 Runtime 输入验证 DPI、捕获、重组、平移、旋转、缩放、选择、测距、禁用、
静置及体更新；读取 GL 纹理像素，检查 GL 状态与 32 次资源创建释放。
导出测试检查 SVG 内嵌 PNG、PDF 图像/alpha/text 资源、文本转义、PNG 尺寸/DPI 与预算。

性能入口逐场景独立进程，2 次预热、8 次固定旋转，记录 JSON 的 median/P95/P99、样本数与缓存。
8 次样本的 P95/P99 均为最大样本，不能解释为稳定的长尾估计。旧 CPU 基准中的 GPU 字段为 null。
新增 `plot_gallery_phase3_probe` / `plot_gallery_phase4_probe` 复用示例场景，在 1680×980 布局、
2.5 倍放大和 1×/2× 下测量全部面板重绘，用 GL_TIME_ELAPSED 查询和 glFinish 后墙钟时间验证。
这些测量不包含窗口 present，也不代表进程 GPU 占用或长期泄漏报告。实际验证机器、结果与预算见
[验收记录](科学绘图三维验收.md)。
