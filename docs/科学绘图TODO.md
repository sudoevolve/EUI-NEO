# 科学绘图 TODO

## 目标与范围

为 EUI-NEO 提供复杂数学图像与科学数据的显示能力，覆盖二维曲线、二维场、三维几何和体数据。
本清单是开发规划，不表示已有 API 或已支持能力；文中的对象名称用于说明职责，正式 API 在实现时确定。
覆盖范围以本清单及对应测试为准，不承诺兼容 MATLAB 的全部绘图函数、脚本或图形对象行为。

优先实现 OpenGL，并验证 GLFW、SDL2 两种窗口后端。绘图数据模型与公共接口保持后端无关；
Vulkan 的实现和验证单独记录，不以接口存在代替后端能力验证。
Octave 解释器接入、计算进程通信、数值求解器和 MATLAB 兼容层不属于本清单范围。

现有 `lineChart`、`barChart`、`pieChart` 是轻量展示组件。折线和柱状图使用归一化值，
没有完整的科学坐标轴；折线按点序号等间距排列，并为线段、数据点创建独立 UI 节点。
科学绘图应建立共用的数据、坐标和渲染体系，保留现有组件的使用契约。

相关文档：[组件](组件.md#图表)、[渲染后端架构](渲染后端架构.md)、[动态纹理](动态纹理.md)。

## 架构与通用约束

建议的职责划分：

```text
PlotFigure：整张图、子图布局、导出
└─ PlotAxes：坐标范围、刻度、变换、投影、交互
   ├─ Line / Scatter / Bar：曲线、点、柱
   ├─ Image / Contour / VectorField：矩阵图像、等高线、矢量场
   └─ Mesh / Surface / Volume：网格、曲面、体数据
```

- [ ] 将科学绘图组织为可选模块，明确构建开关及依赖；未使用时不引入相关重依赖。
- [ ] 分离原始数据、绘图对象、坐标变换、交互状态与 GPU 资源；普通 UI 负责工具栏、标签及布局。
- [ ] 公共 API 不暴露 OpenGL 类型，模块不反向依赖应用或 Octave。
- [ ] 定义数据所有权、共享只读数据、版本更新、线程边界和异步结果的应用时机。
- [ ] 原始数值使用 `double`；屏幕坐标与数据坐标分离，GPU 使用相对原点等方式控制精度损失。
- [ ] 原始数据和显示降采样数据分离，拾取结果能追溯原始索引；导出原始数据不受显示简化影响。
- [ ] 空数据呈现空图，不自动填入示例数据；长度不匹配、无效维度等输入有明确错误行为。
- [ ] 明确定义 NaN、Inf、缺失值及对数轴非正值的处理，不将无效值静默改为零。
- [ ] 原始折线、插值曲线和拟合结果分别表达；数据更新默认不进行数值插值动画。
- [ ] 统一线型、线宽、端点连接、标记、透明度、色图、色阶范围及缺失值颜色的配置。

## 阶段一：基础科学二维绘图

### 数据与坐标轴

- [ ] 接收独立 X/Y 数组，支持非等间距、非单调 X、多条曲线及追加/局部更新。
- [ ] 支持负数、大数、极小数、常量序列、单点数据和 NaN 断线。
- [ ] 实现数据到屏幕及屏幕到数据的映射，包含轴反向、等比例坐标和绘图区裁剪。
- [ ] 支持线性轴、对数轴、自动/手动范围及恢复自动范围。
- [ ] 实现主次刻度、科学计数法、自定义数值格式、轴标签、单位和网格。
- [ ] 根据字体、DPI 和窗口尺寸计算轴边距，避免刻度、标题和标签重叠。

### 图形与交互

- [ ] 实现二维折线、散点、阶梯图、茎状图及可配置数据标记。
- [ ] 实现正负柱状图、分组/堆叠柱状图、直方图，定义分箱和归一化语义。
- [ ] 实现面积填充、误差棒和带状区间。
- [ ] 支持参考线、箭头、文本标注、任意路径和多边形。
- [ ] 支持多曲线图例、曲线显隐及样式区分。
- [ ] 实现平移、以指针为中心的滚轮缩放、框选缩放、视图复位。
- [ ] 实现十字光标、数据探针、点/曲线选择和测距，区分最近原始点与插值位置。
- [ ] 正确处理拖动捕获、移出绘图区后释放、禁用状态及交互中重组。

### 批量渲染与验收

- [ ] 批量绘制线段和点，不为每个采样点建立 UI 节点。
- [ ] 按可见范围筛选并裁剪数据；非单调 X 不使用仅适用于有序数据的查找方法。
- [ ] 按屏幕分辨率降采样，保留峰值、断点及边界相邻线段；缩放后重新选择显示数据。
- [ ] 复用 GPU 缓冲和分块缓存，数据局部变化不触发全量复制和上传。
- [ ] 使用空间索引等方式控制拾取成本，避免每次鼠标移动扫描全部数据。
- [ ] 验证正弦曲线负半轴、非等间距 X、对数轴、大偏移小间距数据及空/单点数据。
- [ ] 验证左右平移与缩放往返时两侧线段稳定，无跳动、断层、消失或错误连接。
- [ ] 建立万点、十万点、百万点场景，分别测量初次加载、平移、缩放、数据更新和静置。

完成条件：上述二维能力有公开文档、示例、数值断言和实际渲染测试；OpenGL 在 GLFW、SDL2 下验证通过，
并满足实施前确定的测试机器、数据规模、CPU/GPU 耗时和资源预算。

## 阶段二：复杂二维图与科学标注

- [ ] 支持多子图布局、共享坐标轴、双 Y 轴及范围/光标联动，避免联动事件递归触发。
- [ ] 实现极坐标轴、角度单位、极坐标曲线和散点。
- [ ] 实现热力图、矩阵图像和颜色条（colorbar），明确矩阵行列与坐标方向的关系。
- [ ] 支持连续/离散色图、线性/对数色阶、手动/自动色阶及缺失值颜色。
- [ ] 实现等高线和填充等高线，支持指定等值、标签及缺失区域。
- [ ] 支持规则网格和非规则网格，明确数据插值及网格拓扑要求。
- [ ] 实现矢量箭头与流线，定义箭头缩放、种子、积分及终止规则。
- [ ] 支持上下标、希腊字母和数学公式排版；列明支持的语法子集与字体回退行为。
- [ ] 科学标注使用共用布局能力，标题、图例、轴标签和普通 UI 可复用公式排版。
- [ ] 支持高分辨率 PNG 导出，可配置尺寸、背景和 DPI，布局随导出尺寸重新计算。
- [ ] 支持 SVG/PDF 矢量输出，保留路径与文本语义，并明确字体嵌入及栅格图层策略。
- [ ] 验证已知标量场的等高线、向量场方向、极坐标映射、多子图联动及导出内容一致性。

完成条件：二维曲线与二维场可以共享坐标、交互和标注；图片及矢量导出有回归样例，
不将窗口截图等同于矢量导出。

## 阶段三：三维科学绘图

- [ ] 在共用数据模型中支持 X/Y/Z 数据及三维坐标轴、刻度和边界框。
- [ ] 实现三维曲线、散点、线框网格、曲面和任意三角网格。
- [ ] 实现三维相机、轨道旋转、平移、缩放、正交/透视投影和视图复位。
- [ ] 引入三维绘图区的深度测试、裁剪、遮挡、面剔除及可配置光照。
- [ ] 支持法线、颜色/标量映射、曲面透明度及等高线投影。
- [ ] 定义透明对象排序策略和适用限制，不以普通 UI 的绘制顺序替代三维遮挡。
- [ ] 实现三维数据拾取、原始数据索引回查、测距和深度正确的标注。
- [ ] 三维渲染与 UI 合成之间正确恢复 GL 状态、处理 DPI、裁剪和 GPU 资源生命周期。
- [ ] 验证相机变换、深度遮挡、网格边界、曲面拾取及反复创建销毁。

完成条件：三维几何能在交互视口内正确显示、旋转和拾取，实际深度和投影行为有测试，
不以 UI 元素的透视变换代替三维绘图能力。

## 阶段四：体数据与高级输出

- [ ] 定义体数据尺寸、轴顺序、采样间距、原点、数值类型和内存布局。
- [ ] 实现轴向/任意方向切片及多视图联动。
- [ ] 实现等值面提取与显示，验证拓扑、法线、边界和缺失值。
- [ ] 实现体绘制及颜色/透明度传递函数，提供采样质量与性能配置。
- [ ] 支持体数据分块加载、显存预算和按需更新，避免默认全量复制大体积数据。
- [ ] 完善相交透明几何与体数据的合成，明确算法的精度和资源代价。
- [ ] 支持三维/体数据高分辨率输出；SVG/PDF 对不可矢量化内容明确使用栅格图层。
- [ ] 保存与恢复视图状态、相机、色阶和标注，使显示和导出可复现。
- [ ] 使用已知体数据验证切片位置、等值面数值及传递函数；记录不同质量设置的性能。

完成条件：切片、等值面与体绘制各有独立示例、正确性测试和内存预算；导出策略明确，
大数据场景能在预算内运行或明确报告容量限制。

## 贯穿各阶段的性能、资源与自动化测试

- [ ] 设置 CPU/GPU 缓存预算、淘汰策略和显式释放入口，明确空闲收缩及资源保留规则。
- [ ] 资源释放等待实际 GPU 使用完成；销毁图表后清理数据引用、纹理、缓冲和事件状态。
- [ ] 静态图按需重绘；动画结束和交互停止后恢复静置，不保留无意义的定时刷新。
- [ ] 为每种图形登记功能、交互、性能和边界用例；新增图形未登记时自动检查失败。
- [ ] 通过实际 Runtime 输入分发执行拖动、滚轮、选择和窗口缩放，断言数据与视图状态。
- [ ] 建立坐标映射、裁剪、刻度、降采样、索引回查和几何生成的数值单元测试。
- [ ] 建立实际像素/图像对照测试，控制字体、DPI 和容差，验证边缘线段及缺失数据行为。
- [ ] 每个场景独立进程执行；单进程内反复交互和创建销毁，避免进程退出掩盖资源增长。
- [ ] 统一执行预热、静置、固定次数操作、多轮重复、销毁、GPU 完成后的回收检查。
- [ ] 记录每次操作 CPU 时间、交互耗时 P95/P99、异步 GPU 计时、进程 GPU 占用和重绘次数。
- [ ] 记录 Private Bytes、Working Set、共享/专用显存、句柄和框架存活资源数量及容量。
- [ ] 分别判断缓存高水位、持续增长和资源未释放，不以“未回到启动内存”作为唯一泄漏标准。
- [ ] 在固定硬件、驱动、Release 配置上串行建立性能基线，多次测量确认回退；缺失指标标记不可用。
- [ ] 功能测试支持无人值守；真实 GPU/呈现性能使用有效桌面和硬件环境，不用最小化窗口冒充实际负载。
- [ ] 输出机器可读结果与汇总报告；失败保存数据集、操作序列、随机种子及必要截图，支持单场景重放。
