## 视觉总纲

- 大面积暖白 `#F7F7F5`，黑色超大粗体；Windows 演示使用微软雅黑粗体 `C:/Windows/Fonts/msyhbd.ttc`。
- 直接使用 EUI-NEO `components::theme::light()` 的默认 button、segmented、toggleSwitch、slider、progress、chart，不自绘另一套控件。
- 背景只保留一张白色底，不使用持续发光球、竖线网格、粒子宇宙。色彩只来自产品状态：蓝、绿、橙、紫。
- 转场不以淡入淡出为主：每次章节切换必须至少包含一种空间动作——文字穿屏、卡片遮挡、`rotateY + perspective` 翻面、`translateZ` 穿越、前后景分层或缩放穿透。

### 2026-09-04 修订：控件过渡根因修复

- 根因：宣传片每帧按时间条件重建组件，但部分内置组件只给轨道/指示器声明了动画，主题变化涉及的文字、边框、背景没有 `animate(...)` 属性，因此颜色在下一帧直接替换；另有整卡固定白色背景，导致 dark theme 看起来像黑色控件叠在白卡上。
- 修正：为 switch、slider track、input field、dropdown field/label 等内置组件补齐 `Color / TextColor / Border / Shadow / Frame` 动画声明，并统一使用 0.72s transition。
- 夜间模式不再绘制黑色遮罩。卡片本身的 surface/background 使用 day→night 的连续插值；卡片从左下向右上运动、旋转并在中点完成主题交换。卡片内部控件按左下到右上的对角线 phase 分批插值，形成整张卡片的蔓延效果。

### 2026-09-04 修订：待机页 GPU 帧循环

- 根因：`promo.root` 无条件注册了 `onFrame`。Runtime 会把注册帧回调的节点视为持续动画，每帧请求重新 compose 与 paint，因此即使还停在“开始播放”页，GPU 也会持续工作。
- 修正：待机页不再注册 `onFrame`，保持事件驱动；仅在点击开始后的播放阶段，以及音频结束后的片尾 3 秒停留阶段注册帧回调。开始按钮触发播放后会进入连续帧循环，片尾计满后自动释放帧循环。
