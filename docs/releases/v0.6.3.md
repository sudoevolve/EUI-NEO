# EUI-NEO v0.6.3

本次版本补齐工具型桌面应用的键盘操作、数据表格和文件对话框，增加长文本历史内存预算及实时曲线绘制路径，并修复异步任务和串口资源生命周期问题。

### 新增与改进

- 控件统一支持 Tab / Shift+Tab 导航与焦点反馈，常用按钮和选择控件支持键盘激活、方向键及首尾定位；模态弹层约束焦点，关闭后恢复原焦点。
- 新增后端无关的控件语义快照，包含角色、名称、值、选中、展开、禁用与焦点状态；图标按钮可显式设置无障碍名称。
- `dataTable` 增加固定行高虚拟化、共享数据源、稳定排序、数值排序、全列关键词筛选、拖动及键盘调整列宽；行点击回调保留原始数据行号。
- 新增系统保存对话框和目录选择，支持建议文件名及 Windows 父窗口绑定，并区分选中、取消和失败；实际文件写入仍由应用负责。
- 输入框增加撤销/重做字节预算，默认合计 8 MiB，可通过 `undoByteBudget(...)` 调整或关闭历史。
- `lineChart` 增加共享采样数据、显式数值范围、可见采样区间、保留峰值的降采样和批量折线绘制，适用于实时信号展示。

### 修复

- 修复异步任务取消、重启或清理后，已排队的旧完成回调仍可能执行的问题。
- 串口对象禁止复制、支持移动转移所有权；打开失败时正确释放句柄并回滚状态。
- 修复 SDL2 事件系统初始化前发送异步唤醒事件的问题。
- 修复表格初始最小列宽、表头与虚拟行宽度对齐，以及表头/行背景覆盖外层圆角的问题。
- 补齐日期、时间、颜色等选择器的键盘操作及弹层焦点恢复。

### 测试与文档

- 新增异步、串口、输入历史预算、虚拟表格、实时曲线、键盘与控件语义的单元测试和后端探针。
- 增加十万行表格与十万采样点曲线的组合交互示例，以及深浅主题表格圆角像素回归检查。
- 正式使用指南、架构和开发文档按主题整理，统一小写英文文件名；计划、审查、验证记录和性能数据迁至 `internal/`。
- 更新官网中英文功能说明、文档目录和链接，增加文档链接、目录覆盖及 Pages 发布产物检查。

### 升级说明

- `.data(sharedData, revision)` 的数据原地更新后必须递增 revision，UI 组合和读取期间不可并发修改共享容器。
- 实时曲线模式不生成逐点标签、tooltip 或数值插值动画；普通轻量图表路径保留。
- 控件语义尚未连接系统屏幕阅读器；本次交付范围为键盘导航、焦点和语义基础。
- `modules/plot` 科学绘图继续在独立 `plot` 分支维护，不包含在本次 main 正式包中。
- 文档旧路径已迁移，入口为 [文档目录](https://github.com/sudoevolve/EUI-NEO/blob/v0.6.3/docs/README.md)。

### 验证

- Windows x64 / MSVC 下，GLFW + OpenGL、SDL2 + OpenGL、GLFW + Vulkan、SDL2 + Vulkan 的 Release 构建及本地测试通过。每组注册 46 项测试；OpenGL 两组各通过 46 项，Vulkan 两组各通过 45 项并按既有规则跳过 Markdown 视口探针。
- 文档和网站检查通过；源码目录与 Pages 布局下的 23 篇现行文档、图片、中英文搜索、文档互链及标题锚点经过浏览器验证。
- 发布流水线另行构建 Windows、Linux、macOS 的运行包和 SDK，并执行单元测试及安装包消费方构建；平台结果以本 tag 的 Actions 记录为准。
