# EUI-NEO v0.6.4

本次为 v0.6.3 的 hotfix，修复鼠标和触摸操作后意外出现通用蓝色焦点框的问题，并消除默认应用构建中的两处 MSVC C4996 警告。

### 交互修复

- 通用焦点框仅在键盘导航或 Enter / Space 操作时显示；鼠标和触摸按下时隐藏，仅移动鼠标不隐藏键盘焦点框。
- 输入方式切换时，即使焦点仍在同一个控件，也会正确重建或移除焦点框。
- 保留鼠标设置焦点、点击回调、Tab / Shift+Tab 导航和控件语义；输入框继续使用自身的聚焦边框，文本输入及 IME 不受影响。
- 弹层自动聚焦和关闭后的焦点恢复沿用当前输入方式，鼠标操作弹层时不再额外显示键盘焦点框。

### 构建修复

- Calgary Gallery 在 MSVC 下使用 `_dupenv_s` 读取环境变量并自动释放副本，保留原有密钥回退逻辑。
- 串口工具使用 C++17 `std::from_chars` 解析 HEX 字节，替换触发警告的 `sscanf`。

### 验证

- Windows x64 / MSVC：GLFW + OpenGL、SDL2 + OpenGL、GLFW + Vulkan、SDL2 + Vulkan 的 `accessibility_probe` 和 `input_runtime_probe` 均通过。
- 回归覆盖鼠标、触摸、右键、键盘导航与激活、同一控件的输入方式切换、控件语义、弹层焦点恢复及输入框自身的聚焦样式。
- Calgary Gallery 和串口工具 Release 构建通过，未再出现上述 C4996 警告。
- 发布流水线继续生成 Windows、Linux、macOS 的运行包和 SDK，并执行单元测试及安装包消费方构建；平台结果以本 tag 的 Actions 记录为准。

### 升级说明

无需修改应用代码或启用额外开关，重新编译即可获得修复。`modules/plot` 科学绘图继续在独立 `plot` 分支维护，本次交互修复同步到该分支；main 正式包的模块范围沿用 v0.6.3。

**完整变更**：https://github.com/sudoevolve/EUI-NEO/compare/v0.6.3...v0.6.4
