# EUI-NEO v0.6.1

本次版本聚焦于窗口生命周期与自绘窗口、Linux 输入体验、组件交互和跨后端构建稳定性。

### 新增与改进

- 新增 `DslAppConfig::onStart()` 一次性启动回调和 `appId()` 桌面应用标识。（#73、#77；@Linductor-alkaid）
- 窗口入口准备首帧后再显示，并在更新期间重新校验 drawable 尺寸、DPI 与指针比例。（#93；PR #94；@Linductor-alkaid）
- 新增 `DslAppConfig::transparent()` 和 `eui::window::framebufferTransparent()`，支持请求透明 framebuffer 并查询平台实际授权状态。（#90；PR #98；@Linductor-alkaid @sudoevolve）
- 新增 `eui::window::beginWindowMove()` / `beginWindowResize()`，支持时将自绘窗口移动和缩放交给窗口管理器。（#89；PR #91；@Linductor-alkaid）
- Linux X11 输入法候选框跟随文本光标。（PR #88；@Linductor-alkaid）
- XIM 已处理的按键不再重复送入应用。（#78；@Linductor-alkaid）
- 受控滚动视图响应程序更新的 offset，且不打断正常滚轮惯性。（PR #88；@Linductor-alkaid）
- 修复 dropdown 弹层层级。（#72；@Linductor-alkaid）
- 修复 slider z-index 导致浮层点击穿透的问题。（#95；PR #96；@Linductor-alkaid）
- 修复 RGBA8/BGRA8 多像素转换。（PR #97；@sudoevolve）
- 修复 OpenGL 图片上传 pixel-unpack 状态污染。（#71；@Linductor-alkaid）
- 修复 Linux 文件对话框诊断混入所选路径的问题。（#76；@Linductor-alkaid）
- 使 BGRA8 单元测试与格式实现保持一致。（#82；@Linductor-alkaid）
- 修复 GLFW 3.3/3.4 兼容。（#79；PR #85；@Linductor-alkaid）
- 修复 Linux X11 GLFW 补丁哈希。（#80；PR #84；@Linductor-alkaid）
- 修复 `-fno-exceptions` 配置下的库和测试构建问题。（#81、#87；PR #86；@Linductor-alkaid）
- 调整项目网站快速接入入口并增加贡献者展示；新增贡献指南，说明 PR 范围、验证、性能数据和仓库体积要求。（@sudoevolve）

### 升级说明

- 新增窗口配置默认不改变原有行为；透明 framebuffer 仍需显式启用。
- SDL2 不支持透明 framebuffer；非 X11 平台的窗口管理器 move/resize 委托返回 `false`，应用应保留原有拖动回退。
- 自绘窗口可使用 `beginWindowMove()` / `beginWindowResize()`；当前原生窗口管理器委托实现为 X11 EWMH，Wayland 支持尚未提供。

### 验证

- GLFW / SDL2 × OpenGL / Vulkan 四种后端组合的 CI 构建、单元测试、后端 probe 和安装包消费者验证通过。
- Linux X11 输入法候选框定位通过 IBus/Xvfb 集成验证。
