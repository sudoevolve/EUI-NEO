# EUI-NEO v0.6.5

本次更新完善桌面界面的布局、表单、菜单和数据选择，统一 SDL2 / GLFW 多指手势，并补齐 bundled GLFW 在 Wayland 下的窗口移动与缩放。包含桌面组件审查发现的四项修复。

### 桌面界面与组件

- 普通复合组件统一支持 `x/y/position/zIndex/margin/flexGrow/flexShrink/ignoreLayout`，布局属性作用于组件根节点，便于组合设置页和工具窗口。
- 新增 `Form` 与 `components::label`：表单统一标签列、控件高度、行距与操作区；常用控件标签垂直居中，基础 `ui.text` 保留顶部对齐。
- Dropdown 根节点只占字段高度，弹层不挤占表单空间；展开时提升子树层级，支持外部按下关闭，目标控件继续收到点击。区分初始展开值 `defaultOpen` 与受控状态 `bindOpen`。
- 新增 `stackingContext` 隔离对话框内部层级，避免内部高 z 节点影响其他对话框；基础 DSL 增加 `onOutsidePress` 和 `requestFocus`。
- Slider 支持业务 `range`、相对最小值的 `step`、键盘方向键、PageUp/Down 与 Home/End；两个端点始终可达，默认范围仍为 0..1。
- DataTable 支持类型化业务对象与列 getter，按数据 identity/revision 缓存；新增单选、多选、稳定业务 key、范围选择、键盘导航及选择语义，保留排序、筛选与虚拟化。
- 新增客户区 `MenuBar`，复用 ContextMenu 级联菜单，支持禁用项、分隔线和键盘导航；方向键移动焦点不会执行动作。
- 主窗口与子窗口新增 `logicalWindowSize`，按显示器 DPI、framebuffer 比例和 uiScale 换算初始客户区尺寸。
- 新增 `desktop_settings` 示例和[桌面表单与菜单指南](../guides/desktop-ui.md)，展示表单、菜单、表格多选以及 Apply / Cancel 草稿状态管理。

### 科学绘图模块

- 同步 `plot` 分支的完整 `modules/plot`，通过 `eui::module_plot` 提供二维曲线、极坐标、热力图、等高线、矢量场、三维/体数据、采集波形与 PNG/SVG/PDF 导出。
- 模块包含 `WaveformBuffer`、`PlotSession`、`LatestValue`，以及最小接入、采集、二维、三维和体数据示例、测试、许可与 SDK 消费工程。API、线程和预算约束见[模块指南](../guides/modules.md#科学绘图)。
- OpenGL/Vulkan 二维视口使用 GPU 光栅化，设备子像素精度不足时回退 CPU；Vulkan 三维/体数据目前仍使用 CPU 参考渲染。同步交换链 acquire 与 transfer 访问阶段，避免缓存 blit 的同步冲突。
- 框架通过通用挂接点注册模块示例、测试及公开头文件安装。绘图模块默认关闭，需显式设置 `EUI_ENABLE_MODULES=ON` 和 `EUI_ENABLE_PLOT=ON`，并链接模块 target。核心 target 不反向依赖模块。
- 高负载 Gallery GPU、数值/空间及交互性能基准默认不构建、不注册到 CTest，需显式设置 `EUI_PLOT_BUILD_BENCHMARKS=ON`；普通功能回归不自动运行这些基准。
- 绘图探针在销毁窗口前释放输入队列，回收 Linux 触摸线程；长时间 Gallery 基准持续处理窗口消息，避免系统误判无响应。

### 触摸与手势

- SDL2 与 Windows/Linux GLFW 共用触点状态机：单指点击、拖动和像素滚动，多指中心平移、缩放与旋转通过 `GestureEvent` 派发。
- 第二根手指加入时取消单指按压与待处理滚动，避免手势结束误触发点击；手指数降为一根后，等待全部触点抬起再开始新的单指操作。
- 全部触点参与几何计算，增减触点重建基线；重合触点、非有限坐标和失焦取消均有处理。
- Windows GLFW 接入 `WM_TOUCH` 并过滤重复鼠标输入，保留 `WM_GESTURE`；Linux GLFW 接入 XInput 2.2 触摸、XInput 2.4 触控板手势，以及 Wayland `wl_touch` 与 `pointer-gestures-unstable-v1`。
- Runtime 捕获手势目标，交互遮罩阻挡手势穿透；切换输入来源及失焦时正确结束或取消旧序列。各平台设备和协议要求见[事件指南](../guides/events.md)。

### Wayland 窗口操作

- bundled GLFW 的 xdg-shell 窗口支持由合成器执行移动和八方向缩放，使用当前左键按下的有效 serial。
- 外部 GLFW、SDL2 Wayland 及 libdecor 窗口的该操作仍不支持，接口返回 `false`；不会模拟全局窗口定位。

### 审查修复

- 修复安装 SDK 漏装 `eui/detail/window_size.h`，外部工程使用 `find_package(EuiNeo)` 与标准应用入口可正常编译。
- 修复关闭 Dropdown 时恢复旧焦点、抢走外部输入框焦点的问题；点击外部输入框关闭弹层后可以直接输入，Escape 关闭仍支持焦点恢复。
- 修复 DataTable 虚拟行复用导致键盘焦点转移到其他业务行、Space 操作旧行或视口跳回的问题。焦点跟随业务 key；焦点行离开已构建窗口时清除焦点并保留选择。
- 修复 Slider 范围不能被步长整除时，从最大值向下移动跳过相邻刻度的问题。例如 `range(10,110).step(30)` 从 110 向左移动到 100；同时覆盖小数步长和大于范围的步长。
- 补齐桌面指南的网站中英文目录、sitemap 与 `llms.txt` 索引。

### 验证

- Windows x64 / MSVC：GLFW + OpenGL、SDL2 + OpenGL、GLFW + Vulkan、SDL2 + Vulkan 的桌面组件、表格选择与焦点 Runtime 回归测试通过；弹层测试覆盖 100% / 150% / 200% 缩放，OpenGL 路径读取 framebuffer 验证绘制顺序。
- 安装 SDK 后，以独立消费工程通过 `find_package(EuiNeo)` 构建公共头文件消费方与标准应用入口，并运行消费方测试。
- 科学绘图合并完成四种 Windows 后端组合的 Release 构建和功能测试。首次验证包含性能基准（OpenGL 每组合注册 79 项，Vulkan 每组合注册 73 项；平台不适用项跳过）；随后将基准改为默认关闭，并检查 CTest 注册隔离。Vulkan 开启同步验证，未报告验证层错误。
- OpenGL / Vulkan 绘图 SDK 独立消费工程构建与测试通过；检查了公开头文件、导出路径及关闭绘图模块时的配置隔离。
- Linux / WSL Ubuntu 24.04：GLFW、SDL2 的 OpenGL 桌面交互回归在 Xvfb 下通过。多指手势已有 X11 / Wayland 合成输入与平台转换测试覆盖。
- Linux 绘图补充验证：五项数值、精度、导出、波形与应用单元测试，以及六项 GLFW + OpenGL 窗口/交互探针在 Xvfb 下通过；此项使用 Mesa 软件渲染。
- 文档检查及差异空白检查通过。
- 尚未完成物理触屏、触控板和 macOS 实机验收；WSLg 未提供触控板手势协议，相关转换使用回调注入验证。系统、驱动或合成器未报告的手势不会补造，Linux Vulkan 未单独验证。

### 升级说明

原有组件 API、字符串行表格和原生单位 `windowSize` 保持可用。需要按 compose 逻辑尺寸创建窗口时使用 `logicalWindowSize`；布局仍以实际 `screen.width/height` 为准，窗口位置与最小/最大尺寸继续使用原生单位。

类型化表格原地修改数据、getter 或 key 规则后必须递增 revision；业务 key 必须唯一，数据不能与 compose 并发修改。`Signal` 保持显式绑定语义，业务的 Apply / Cancel 应由应用维护编辑草稿与已保存状态。
