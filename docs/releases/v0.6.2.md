# EUI-NEO v0.6.2

本次版本聚焦于触摸输入、长内容组件和文本渲染的性能与资源占用，并补充了窗口后端兼容性与回归测试。

### 新增与改进

- SDL2 后端新增单指触摸输入：触摸按下、移动和抬起会转换为 pointer 事件，`PointerEvent::touch` 可用于区分触摸来源。（@sudoevolve）
- 滚动事件新增像素级触摸滚动数据；滚动容器按 DPI 换算触摸位移，且触摸滑动后不会误触发 click。（@sudoevolve）
- Markdown 仅构建视口附近内容，改善大文档的初始构建和滚动资源消耗。（PR #117；@Linductor-alkaid）
- 固定字号字体面缓存 glyph advance，降低重复文本度量的成本。（PR #114；@Linductor-alkaid）
- 字形图集改为按需分配，OpenGL 和 Vulkan 仅上传已使用区域，降低首次文本渲染的内存和上传开销。（@sudoevolve）
- SDL 窗口移动/缩放 fallback 不再限于 X11，可供其他支持的平台调用。（PR #111；@Linductor-alkaid）
- Gallery 标题和展示文本统一为 `eui-neo` / `EUI NEO`。（@sudoevolve）
- 新增软件渲染后端的 TODO 文档，记录后续实现范围。（@sudoevolve）

### 性能

- 三次 Release 对比中，一个文本按钮的私有内存由 66.6 MB 降至 58.9 MB，约减少 7.7 MB；十个文本按钮由 67.5 MB 降至 58.9 MB，约减少 8.6 MB。空窗口内存维持 44.9 MB，空白按钮无显著变化。

### 测试与文档

- 增加带透明 Alpha 的 stride RGBA 图像流测试。（PR #107；@Linductor-alkaid）
- 新增文本度量缓存、Markdown 视口、触摸 pointer 输入和窗口 fallback 的测试与 probe。
- 增加 Markdown 视口和文本测量性能报告、基准数据与复现脚本。

### 升级说明

- SDL2 可提供单指触摸 pointer 和像素级滚动；当前仅跟踪第一根活动手指，不支持多指缩放、旋转或手势仲裁。
- GLFW 后端仍依赖操作系统将触摸映射为鼠标或滚动事件，不能提供原始触摸标记和多点触控。
- `ScrollEvent` 新增 `pixelX` / `pixelY`，现有仅使用 `x` / `y` 的调用无需修改。

### 验证

- 新增的图像流、文本度量缓存、Markdown 视口、pointer 输入及窗口 probe 覆盖相关行为。
