# 网络请求

页面代码通过 `eui/network.h` 使用网络能力；底层实现位于 `core/platform/network.h` / `core/platform/network.cpp`。当前主要服务两类能力：

- 图片节点加载 `http/https` 图片和 Bing 每日图。
- 页面示例请求文本 API，再把结果写入 `ui.text(...)`。

后台执行由 内部 async 统一调度；页面开发自己的耗时任务推荐使用 `app::async`，见 `docs/异步.md`。

## 平台支持

- Windows：优先使用 libcurl；如果 CMake 没找到 curl，则使用系统 `URLDownloadToFileA`。
- Linux / 其他非 Windows：使用 libcurl。CMake 在非 Windows 平台要求 `CURL::libcurl`。

## 文本 API

```cpp
eui::network::requestText(
    "bing.meta",
    "https://www.bing.com/HPImageArchive.aspx?format=js&n=1&idx=0&mkt=zh-CN");

const eui::network::TextResult result = eui::network::textResult("bing.meta");
if (result.ready && result.ok) {
    ui.text("api.text")
        .size(520.0f, 72.0f)
        .text(result.body)
        .wrap(true)
        .build();
}
```

`requestText` 只会为同一个 key 启动一次后台请求。请求完成后会通过统一 async 队列回到 UI 主线程，唤醒 GLFW 事件循环，并让 `include/eui/dsl_app.h` 重新 compose 页面。

## JSON

`eui/json.h` 提供只读 JSON 文档和轻量值视图，不暴露底层 yyjson 类型：

```cpp
eui::json::Document document;
if (!document.parse(result.body)) {
    const eui::json::ParseError& error = document.error();
    // error.code、error.offset、error.message
    return;
}

const eui::json::Value images = document.atPointer("/images");
const eui::json::Value first = images.at(0);

std::string copyright;
if (first.get("copyright").string(copyright)) {
    // 使用 copyright
}
```

`Value` 支持 null、bool、有符号整数、无符号整数、浮点数、字符串、数组和对象。数组使用 `size()` / `at(index)`，对象使用 `size()` / `get(key)`，任意节点都可以使用 `atPointer()`。`Value` 不拥有内存；所属 `Document` 被重新解析或其存储被销毁后，已有视图不可继续使用。

`gallery` 的 About 页展示了 Bing API 文本结果。

## 图片网络请求

```cpp
ui.image("remote")
    .size(260.0f, 150.0f)
    .source("https://example.com/picture.png")
    .radius(16.0f)
    .build();
```

网络图片会通过统一 async 线程池下载到系统临时缓存目录，再按本地图片解码并上传纹理。下载完成后 Runtime 会重绘图片区域。

## Bing 每日图

```cpp
ui.image("bing")
    .size(260.0f, 150.0f)
    .bingDaily(0, "zh-CN")
    .radius(16.0f)
    .build();
```

`bingDaily(idx, mkt)` 会请求 Bing `HPImageArchive` API，解析返回 JSON 中的图片 URL，然后下载图片。

同一套解析和下载能力也可以给取色 API 使用：

```cpp
const eui::Color accent = eui::image::themeColor(
    "bing://daily?idx=0&mkt=zh-CN",
    {0.38f, 0.72f, 0.96f, 1.0f});
```

当远程图片仍在下载时，`themeColor` 返回传入的 fallback；下载完成后再次 compose 会得到缓存图片采样出的主题色。

## 当前限制

- 现在只有 GET 请求。
- 还没有暴露 header、body、取消、进度、重试策略。
- 文本 API 结果是原始字符串。需要 JSON 时使用 `eui::json::Document`：它基于内置 yyjson，支持标准 JSON 转义、类型判断、对象/数组访问和 JSON Pointer。解析失败时通过 `document.error()` 获取错误码、字节位置和说明。
