# 科学绘图

`modules/plot` 是可选的科学二维绘图模块，命名空间为 `modules::plot`，链接目标为
`eui::module_plot`。普通 `lineChart`、`barChart`、`pieChart` 的契约保持不变。

## 构建与最小使用

源码接入开启 `EUI_ENABLE_MODULES` 和 `EUI_ENABLE_PLOT` 后链接模块。顶层模块默认启用；
作为子目录接入时需要显式开启模块发现。关闭模块或省略整个目录不会影响核心构建。
安装包中使用 `find_package(EuiNeo CONFIG REQUIRED)` 和相同模块目标。

```cpp
#include "modules/plot/plot.h"
#include "modules/plot/figure.h"

modules::plot::Plot plot;

void initializePlot() {
    modules::plot::Series line;
    line.name = "Measurement";
    line.data = modules::plot::Data({0, 0.1, 2, 3}, {-1, 2, 0, -2});
    plot.setSeries({line});
    modules::plot::Axes axes;
    axes.x.label = "Time";
    axes.x.unit = "s";
    plot.setAxes(axes);
}

// 在所属窗口 compose 中调用。数据初始化只做一次。
void composePlot(eui::Ui& ui) {
    plot.compose(ui, "measurement", 800, 500);
}
```

## 多子图与范围链接

`Figure` 管理多个 `Plot`，按均分网格组合；默认一列，可用 `setColumns()` 调整。每个
子图仍独立持有数据、Y 轴、交互状态和 GPU 资源。`linkX()`、`linkY()` 和 `linkCursor()`
接受至少两个子图索引；`synchronizeLinks()` 将检测到的首个范围或十字光标变更单向应用给
同组其他子图。它不使用回调互调，因此不会递归触发联动。`compose()` 会在排版前自动调用
同步，批量更新或无窗口测试也可显式调用。

```cpp
modules::plot::Figure figure;
auto& upper = figure.addPlot();
auto& lower = figure.addPlot();
figure.setColumns(1);
figure.linkX({0, 1});

void composeFigure(eui::Ui& ui) {
    figure.compose(ui, "signals", 800, 500);
}
```

链接范围首次同步时以链接组第一个子图为准；首次光标同步则使用第一个非空光标。之后范围
或光标发生变化的第一个子图成为该轮来源；同一轮多个子图同时变更时不定义优先级。链接组
可以重叠，但重叠组按注册顺序同步。光标以数据坐标传播；目标坐标轴无法映射时不显示十字线。

完整应用见 `examples/scientific_plot.cpp`：10 万个非等间距正弦采样、负半轴和 NaN 缺口。
`Plot::releaseGpu()` 必须在所属窗口设备销毁前执行，主窗口可使用
`DslAppConfig::onShutdown()`。窗口关闭后的 C++ 全局析构不能再调用 OpenGL。
调用方在 UI 回调之外更新数据或配置后应调用 `app::requestUpdate()`。
模块自身不依赖应用入口实现。

阶段二统一总览见 `examples/scientific_plot_phase2.cpp`，单窗口 4×2 面板集中展示 Figure 双 Y
轴与光标联动、极坐标、热力图/colorbar、等高线与填充带、数学标注、规则网格矢量箭头、RK4
流线以及 PNG/SVG/PDF 导出预览。启动时会在工作目录生成 `scientific_plot_phase2.png`、
`scientific_plot_phase2.svg` 和 `scientific_plot_phase2.pdf`。

## 数据、坐标和错误行为

`Data(x, y)` 复制两个等长 `std::vector<double>`，保持原始次序，允许非单调 X。
空数据保持空图；不注入默认采样。`append()` 和 `replace()` 返回新快照，旧快照保持有效。
底层每块最多 4096 点，未变化块共享所有权；更新会复制块指针表和受影响数据块，
不会复制全部原始样本。`revision()` 在非空更新时递增，但不是跨数据对象的全局身份。
`points()` 始终导出原始点，包括 NaN/Inf，不受显示降采样影响。

数据快照可跨线程只读共享；轴、绘图控制器、索引和 GPU 资源只在所属窗口 UI 线程使用。
工作线程生成新 `Data`，由应用通过现有异步机制投递到 UI 线程，在下一次 compose 前应用。
模块不自动排队或取消异步任务。快照析构释放共享块最后一个引用，不要求 GPU 同步。

NaN、Inf 或任一对数轴上的非正坐标表示缺失点：不参与自动范围、拾取或几何生成，
折线在此断开。无效值不会被置零。空轴默认线性 `[0,1]`、对数 `[1,10]`；
常量和单点范围自动扩展，单点绘制标记。数据更新不播放插值或拟合动画。

`Axis` 支持 `Linear`、`Log10`、反向、手动范围和恢复自动范围。`Axes::toScreen()` 与
`toData()` 使用双精度，屏幕 Y 向下，数据 Y 向上；范围外允许映射，几何生成负责裁剪。
`equalize(viewport)` 扩展线性轴至相同数据单位/逻辑像素，对数轴返回 false。
大偏移小间距先相对原点归一化，之后才转换 GPU float。

`ticks()` 返回主次刻度，支持科学计数法和 `formatter`；UI 当前显示主刻度与主网格。
轴标题与单位使用普通文本。左边距按字体实测刻度宽度计算；尺寸至少 160×120，
过密 X 标签会省略。极窄尺寸的长标题、反向轴标签布局和全部次刻度显示仍有改进空间。
`compose(..., dpi)` 的 dpi 控制纹理物理尺寸，默认 1；调用方应传入窗口实际 DPI。

XY 长度不等、无效区间、非法样式或非法尺寸抛出 `std::invalid_argument`；
原始索引和替换范围越界抛出 `std::out_of_range`；资源预算超限抛出 `std::length_error`。
数值累计溢出使用 `std::overflow_error`。坐标映射失败返回 `std::nullopt`。
GL 初始化、Shader 或 framebuffer 失败使用 `std::runtime_error`。

## 图形与交互

`Series::graph` 支持：

| Graph | 数据含义 |
| --- | --- |
| Line | 按原始顺序连接有效样本 |
| Scatter | 绘制原始样本标记 |
| Step | 后置阶梯，先水平再垂直 |
| Stem | 从 `style.baseline` 到样本 |
| Bar | `style.barWidth` 为数据单位柱宽；`baselines` 可提供逐柱基线 |
| Area | 折线到基线的填充；跨基线在交点拆开 |
| ErrorBars | `lower`/`upper` 为非负上下误差，标记尺寸作为端帽宽 |
| Band | `lower`/`upper` 为绝对 Y 包络，共用 data 的 X |

每个序列默认使用 `YAxis::Primary`。调用 `setSecondaryYAxis(axis)` 后，将序列的 `yAxis`
设为 `YAxis::Secondary` 可使用独立的右侧刻度和范围；两个 Y 轴分别自动拟合各自可见序列，
X 轴自动范围仍覆盖全部可见序列。次轴不存在时，绑定次轴的序列使用主轴以保持可见。

## 极坐标

`PolarAxes` 和 `PolarPlot` 使用 `Point.x` 表示角度、`Point.y` 表示非负半径。角度默认使用
弧度；`setAngleUnit(AngleUnit::Degrees)` 可切换为度，`setZeroAngle()` 与 `setClockwise()`
分别配置零角和正角方向。`radius` 是普通 `Axis`，支持自动、手动和对数范围；自动范围从零
覆盖有效半径。映射使用居中圆形视口，负半径、无效值和圆盘外的屏幕坐标返回空值。

`PolarPlot` 复用离屏 OpenGL 渲染器，绘制径向主刻度圆、八条角度辐条，以及 `Graph::Line`
和 `Graph::Scatter`。其他 `Graph` 类型会抛出 `std::invalid_argument`；当前极坐标图没有平移、
缩放、拾取或路径标注。统一示例见 `examples/scientific_plot_phase2.cpp`。

## 标量场与色阶

`ScalarField(rows, columns, values, xRange, yRange, origin, sampling)` 保存不可变的双精度矩阵，
其中 `values[row * columns + column]` 是 `value(row, column)`。`FieldOrigin::LowerLeft` 将第 0
行绘制在底部，`UpperLeft` 将其绘制在顶部；坐标范围、原点和 `CellCenters`/`GridPoints` 语义
均随快照保存。CellCenters 以每个值填充一个矩形；GridPoints 为每四个有限顶点生成一个单元，
其颜色使用四值算术平均。任一非有限顶点会使该单元使用缺失颜色。

`ColorScale` 支持 `Viridis`、`Plasma`、`Turbo`、灰度和纯色映射，可设置线性/对数
`ColorScaleMode`、自动/手动范围、连续或 2--256 级离散色阶及缺失颜色。对数自动范围仅采样
正值。`HeatmapPlot` 将标量场和同一色阶生成的纵向 colorbar 渲染到一张离屏纹理，并显示色阶
的最小、中点和最大标签；当前热力图尚未提供坐标轴交互。统一示例见 `examples/scientific_plot_phase2.cpp`。

`marchingSquares(field, levels)` 为严格递增的有限等值列表生成数据坐标中的折线段；四角任一
非有限值的网格单元会完全跳过，鞍点按四角均值选择连接方式。`automaticContourLevels(field, count)`
从有限数据范围生成均匀的内部等值，`contourLabels()` 为每级选择线段中点作为标签锚点。
`filledContours(field, levels)` 返回 $n+1$ 个填充带，首尾带的边界分别为负、正无穷；显示时应以
有限场范围夹取代表值再映射色阶。统一示例见 `examples/scientific_plot_phase2.cpp`。

`RectilinearField(x, y, values)` 支持不等间距但严格递增的规则直角网格，`values[row * columns +
column]` 表示 $(x[column],y[row])$ 顶点；`interpolate()` 仅在所在单元四个顶点均有限时执行双线性
插值。`TriangulatedField(points, values, triangles)` 支持非规则网格，调用方必须提供索引合法、互异且
非退化的三角拓扑；模块不会猜测连接关系或重采样，`interpolate()` 仅在第一个包含点的有效三角形内
执行重心插值。`rectilinearTiles()` 和 `triangulatedTiles()` 生成可直接提交给 Renderer 的色块批次。

`VectorField` 由两个共享坐标的 `RectilinearField` 分量组成，箭头仅从规则网格顶点取样；
`vectorArrows()` 的 `scale` 控制数据空间长度，低于 `minimumMagnitude` 的样本跳过。`streamlines()`
从调用方提供的种子开始，以固定步长执行四阶 Runge-Kutta；每条结果保留 `sourceIndex`，遇到越界、
缺失、低速或达到 `maxSteps` 即终止，可选择同时积分正反方向。当前不对非规则场隐式重采样，
统一示例见 `examples/scientific_plot_phase2.cpp`。

数学公式排版目前暂不提供。Plot 标题、轴标签和标注只接受普通 UTF-8 文本；FreeType 负责字形
加载和回退，但不负责 TeX/MathML 的公式布局。此前的自制 parser 已移除，不再把不完整的字符拼接
称为公式支持。统一示例中的相关位置使用普通说明文字。

轻量且目标覆盖约 90% 常见科研公式的方案：保留原始 TeX 字符串，采用成熟 TeX 子集解析器生成
结构化 MathML/盒模型；实现 atom spacing、上下标、分式、根式、括号伸缩、运算符、Greek、矩阵和
字体回退；再使用 KaTeX/MathJax 或同等成熟引擎生成 SVG，复用现有 NanoSVG 栅格化到 UI。SVG/PDF
导出保留公式 SVG/path，普通文本继续使用 FreeType。必须为解析失败、缺字形、超大嵌套和导出一致性
建立测试；在正式第三方依赖接入前，该 TODO 不勾选。

`ExportScene` 是不依赖窗口和 GPU 的二维场景树。`writePng()` 接收 RGBA8 行优先像素并写入尺寸和
DPI 元数据；`writeSvg()` 保留 path/text 元素；`writePdf()` 使用模块内最小 writer 保留路径和
Helvetica 文本语义。`ExportScene.rasters` 接收不可矢量化内容，SVG 内嵌 PNG，PDF 使用 RGB
image XObject 和 alpha soft mask，不把栅格内容伪装成矢量路径。
示例会生成 `scientific_plot.png`、`scientific_plot.svg` 和 `scientific_plot.pdf`。

线宽和标记尺寸为逻辑像素，颜色为 straight RGBA。标记支持方形、圆形、菱形、十字。
折线支持实线、虚线、点线；虚线相位从每条裁剪后的线段起点开始。
当前线段使用平端和独立线段连接，半透明交点可能叠加，尚无可配置 join/cap。

`arrangeBars(x, values, stacked, width)` 生成分组或正负独立累计的堆叠柱。将每组的
`tops`、`baselines`、`width` 分别填入 Bar 序列的 `data`、`baselines`、`style.barWidth`。
`histogram(samples, edges, normalization)` 显式指定严格递增的有限箱边界；
左闭右开，最后一箱包含右边界。非有限值和箱外样本忽略。Probability 的总和为 1，
Density 的加权面积为 1；分母为纳入分箱的样本数量。零样本的结果全零。
非等宽直方图可使用 `bars()` 分别绘制，Bar 序列本身使用统一柱宽。

`setPaths()` 支持参考折线、闭合路径和凸多边形填充，路径顶点使用数据坐标。
箭头可显式提供箭杆和箭头两翼的路径；没有自动箭头尺寸接口。非凸填充明确拒绝。
`setAnnotations()` 将普通文本放在数据位置，绘图区外不显示。

- 左键拖动：平移。
- 滚轮：围绕指针缩放；右键：恢复自动范围。
- Shift + 左键框选：缩放到矩形数据范围。
- 点击图例：显隐对应序列。
- 鼠标靠近原始点：显示十字光标，`probe()` 返回序列和原始索引。
- 点击原始点：`selection()` 保存选择。
- Ctrl 点击两处：`measurement()` 返回数据坐标欧氏距离；轴单位不同时由调用方解释单位。

拾取针对原始样本，不将降采样点或线段插值冒充原始数据。当前没有线段插值位置拾取。
拖动状态独立于 UI 重组，Runtime 负责捕获；禁用时取消拖动、清除探针。
回调使用弱引用，不延长控制器生命周期。

## 渲染、性能与资源

原始数据 → 双精度映射/裁剪 → 屏幕三角形 → 模块 OpenGL 离屏纹理 → 普通 image UI。
原始数据、坐标模型、交互状态和 GPU 资源分开；公共 API 不含 OpenGL 类型。
普通 UI 负责坐标、标题、图例和布局，每条采样曲线不会创建逐点 UI 节点。

连续屏幕列保留首、末、极小、极大值，维持原始索引次序并保留缺口；非单调 X
按原始顺序遍历，不使用有序数组二分。裁剪保留跨越绘图区的线段和两侧相邻点。
视图变化后重新选样。它是显示近似，不是插值或拟合；阶梯与面积也使用该近似。
散点、标记、柱与误差棒保留原始样本。非常复杂的非单调轨迹不保证缩减到固定顶点数。

索引以 16×16 逻辑像素分桶，只索引可见原始点；移动查询访问相邻桶。大量重合点仍可能
集中在同一桶，最坏拾取成本尚无严格上界。视图或数据改变时目前重建整个显示几何和索引。
原始数据局部更新只复制相关块；GPU 缓冲比较 4096 顶点块，布局不变时仅上传变化块。
缓冲扩容或几何布局改变可能导致大部分上传，尚未实现原始块到 GPU 块的增量缓存。

`Budget` 默认顶点缓存 64 MiB、纹理 64 MiB；GPU 顶点缓冲另保留一份 CPU 上传镜像。
预算检查发生在 Renderer 提交时，不限制原始 Data、几何生成中间结果和拾取索引。
它不是完整进程内存预算。逻辑几何视口最多 32768×32768，物理纹理还受 GL 上限约束。
静态绘图只在数据、轴、路径、尺寸或 DPI 改变时重绘，无定时刷新。
`releaseGpu()` 显式释放模块缓存；空闲时保留高水位容量，没有自动淘汰策略。

GL 状态在模块绘制后恢复。纹理经现有外部 GPU 图像接口导入，UI 的旧图像引用等到
GPU 完成后退休；模块释放 GL buffer/framebuffer/program 时由 GL 处理已提交命令的资源引用。
多窗口必须使用各自 Plot，不能跨设备共享 Renderer。绘图区背景固定不透明深色，避免
离屏 alpha 预乘后被 UI 重复合成；二维 Renderer 当前不支持配置透明背景或直接导出。
三维输出的独立背景和导出接口见 [三维与体数据](科学绘图三维与体数据.md)。

## 验证入口与支持边界

```powershell
cmake -S . -B build-plot -DEUI_DEPS_MODE=bundled -DEUI_BUILD_TEST_FIXTURES=ON
cmake --build build-plot --config Release --target scientific_plot scientific_plot_phase2 plot_numeric plot_geometry plot_vector plot_export plot_runtime_probe plot_contour_runtime_probe plot_benchmark
ctest --test-dir build-plot -C Release -R "^plot_" --output-on-failure
```

SDL2 使用独立目录和 `-DEUI_WINDOW_BACKEND=sdl2 -DEUI_RENDER_BACKEND=opengl`；
由于仓库不携带 SDL2，使用 `EUI_DEPS_MODE=auto`。

`plot_numeric` 覆盖原始快照、范围、精度、Figure 链接和极坐标映射；`plot_geometry` 覆盖各图形、
极坐标曲线/散点、标量场、等高线、缺口、峰值、裁剪、直方图和原始索引；`plot_runtime_probe` 创建真实窗口，检查
笛卡尔、极坐标、热力图、颜色条和等高带像素、GL 状态，`plot_contour_runtime_probe` 在独立窗口中检查
等高带与等值线像素；
1×/2× DPI、捕获、重组、禁用、滚轮、框选、静置和反复释放。
基准对 1 万、10 万和 100 万点分别执行独立进程，三次预热、20 轮固定操作，输出 JSON。
当前基准为 CPU 数值/几何测量，不是实际 GPU 呈现性能；未采集指标输出 null。

渲染仅提供 OpenGL 实现。Vulkan 下可构建数值模型，调用 Renderer 明确报错，绘图图形示例
与 GPU probe 不生成。三维与体绘制的实现和限制见 [三维与体数据](科学绘图三维与体数据.md)；路线图与未完成验收项
集中维护在 [科学绘图 TODO](科学绘图TODO.md)，不能以此模块存在推断完整清单已完成。
