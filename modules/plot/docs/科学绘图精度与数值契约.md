# 科学绘图精度与数值契约

`plot` 提供基础数据、坐标、几何和渲染接口。数据精度、算法误差与显示精度是三个不同的契约。
屏幕像素或导出颜色不能作为原始测量值。

## 数据类型与接入

| 入口 | 存储与转换 | 使用约束 |
| --- | --- | --- |
| Data、ScalarField、RectilinearField | double | 常见平台的 binary64 为 53 位有效二进制位 |
| WaveformBuffer 的 UInt8 / Int16 / UInt16 | 紧凑整数，查询和映射时转为 double | 三种整数的全部取值均可精确转换 |
| 应用的 float32 数据 | 显式转 double 后接入 | 有限 float32 可精确提升；此前损失不会恢复 |
| VolumeData | 按布局读取，包括 Float64 | 布局、步长、端序及所有者生命周期必须匹配头文件契约 |
| 二维 Vertex 和 GPU 数据 | 局部屏幕/场景空间 float | 用于显示，不作为原始科学计算结果 |
| PNG 和三维离屏图像 | RGBA8 | 每通道 8 位，不能保存原始标量精度 |

二进制浮点不精确表示大多数十进制小数。所有整数仅在绝对值不超过 2^53 时能保证逐单位表示。
例如绝对时间约 1.7e9 秒时，double 间隔约为 238 ns；先以整数安全地减去时间原点，再转为
相对秒，可避免转换为绝对秒时先损失低位。整数相减仍需检查溢出；已舍入的 double 不能恢复低位。

## 数值范围与缺失值

轴范围必须有限且严格递增，Log10 还要求下界大于零。手动范围不被自动 fit 覆盖。
常量自动范围扩展为可表示的有限非零区间；极大值允许单侧扩展，正 subnormal 对数常量不会
扩展到零。未提供有效数据时使用默认范围。

线性插值避免直接构造可能溢出的异号跨度；对数轴使用相对差的 log1p 路径，保留相邻大数间距。
ColorScale 使用相同轴映射规则，有效范围外标量夹取到端点色；NaN/Inf 以及 Log10 非正值使用
missingColor。Viridis、Plasma、Turbo 使用标准 256 点 RGB 表并在相邻表项间线性插值，CPU 与
OpenGL 场景着色器共享表源。许可见 modules/plot/licenses/plot-colormaps.txt。

缺失样本断开原始折线；标量场含非有限顶点的单元不生成等值线。鞍点使用双线性渐近判别，
判别恰为零时采用固定连接。填充等值带按固定对角线将单元拆成线性三角形，与双线性等值线
使用不同插值模型；鞍点附近边界可能不同。自动等值线只返回严格内部、有限、递增且不重复
的等值，区间内没有足够可表示数时返回数量减少。

## 显示、拾取与格式化

CurveKind::Raw 保留原始折线。Interpolated 添加线性中点，不是样条；Fitted 为当前索引前后
最多五点的移动平均，不是统计回归或误差估计。Fitted 忽略邻域内非有限 Y，缺失点自身保留；
邻域可跨过缺失点影响两侧，严格分段滤波应在接入前处理。两种模式不改写 Data，拾取返回原始样本。

显示抽稀按屏幕列保留首尾与极值及原始索引，用于控制几何数量，不作为新的完整测量序列。
默认主刻度标签重名时自动增加有效位，最高到 max_digits10；自定义 formatter 完全由应用控制。
长标签可能需要增大边距或采用相对原点标签。

Vulkan 二维 GPU 路径在提交顶点前将屏幕坐标量化到 1/256 物理像素，使用三角形列表的 top-left
边覆盖规则，避免同一半透明图元的公共边重复混色；不同图元实际重叠仍分别混色。子像素精度
低于 8 位的设备回退 CPU 参考光栅器。这只是显示覆盖规则，不改写原始 double 数据或拾取结果，
不提供 MSAA；硬件混合舍入可能带来 1 个 RGBA8 通道值的误差，不承诺与 OpenGL 边缘位级相同。
render() 的二维离屏纹理沿用下起点约定，直接组合到 UI 时需要 flipVertically()；
uploadRgba() 接受左上起点 RGBA8，直接组合时不翻转。Plot/Plot3D 已处理各自约定。

## 验证方法

原始整数和快照使用精确相等；算法分别规定绝对误差、相对误差或 ULP；坐标映射同时检查
源值可表示性与屏幕偏差；CPU/GPU 图像按通道误差比较，不要求不同驱动逐像素位相同。
normalize(denormalize(t)) 受数据区间内浮点间距限制，不保证任意屏幕位置可精确反解。
宽对数域涉及 log/exp，不承诺全域 1 ULP、任意精度或跨平台位级确定性。

```powershell
cmake -S . -B build-plot -DEUI_BUILD_TEST_FIXTURES=ON -DEUI_BUILD_APPS=OFF -DEUI_DEPS_MODE=bundled
cmake --build build-plot --config Release --target plot_numeric plot_precision plot_geometry plot_export plot_waveform plot_spatial
ctest --test-dir build-plot -C Release -R '^plot_(numeric|precision|geometry|export|waveform|spatial)$' --output-on-failure
```

plot_precision 覆盖极值色阶、相邻浮点数对数区间、色表参考点、取反不变的鞍点拓扑、有限等值线
插值、拐角面积与端帽、巨大数值曲线和刻度标签。plot_export 检查 alpha、非法路径、坐标序列化
与 locale。plot_spatial_runtime_probe 在实际 OpenGL 上比较 CPU/GPU 标准色表，需要图形设备。
每个发布平台需分别执行；某个平台通过不等于所有后端均已认证。

样本保真回归还遍历 Int16/UInt16 全取值、UInt8 全取值的重复序列，并固定种子生成 100000 个
float32 位模式，将有限值提升到 double 后检查快照位模式；同时覆盖 signed zero、subnormal 和
double 极值。该测试检查存储链路，不代表所有科学算法具有相同误差。
