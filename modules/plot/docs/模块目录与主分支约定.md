# 模块目录与主分支约定

2026-11-02 起，科学绘图的全部实现与配套资料集中在 `modules/plot/`。主分支只保留通用框架
能力，plot 分支相对更新后的主分支只增加此目录；不在顶层 CMake、通用文档和公共测试中
硬编码 plot。仓库 `internal/plans/scientific-plotting.md` 保留原有规划，本目录 `docs/科学绘图TODO.md`
记录本模块的实际完成情况。

| 目录 | 职责 |
| --- | --- |
| 根目录的 .h / .cpp | 基础数据、坐标、几何、渲染与导出 API |
| cmake/ | 模块的构建注册、示例、测试与安装规则 |
| docs/ | API、快速开始、数值契约、历史基准、验收和商业交付草案 |
| examples/ | 可选示例与独立二进制 SDK 消费者 |
| tests/ | 单元、窗口探针、基准和 find_package 消费者 |
| licenses/ | 色表与当前 SDK 依赖的许可说明 |
| scripts/、tools/ | 发布门禁与色表生成工具 |

## 接入与边界

主分支通过现有模块发现加载 `CMakeLists.txt`。模块登记通用
`EUI_NEO_MODULE_BUILD_SCRIPTS`，待框架 app/test helpers 就绪后注册可选目标；公开头文件由
模块自行列举安装。主分支的通用 Vulkan 同步修复是共享后端修复，不由 plot 在构建期间打补丁
或替换核心源文件。

对应主分支提交为 `6cb6d4b`（Vulkan 同步修复）和 `0c961d6`（通用模块构建与安装挂接点）。

关闭 `EUI_ENABLE_PLOT` 或移除此目录后，框架配置不得注册 plot 目标和测试。安装包仅公开
16 个 API 头文件，不复制实现头、测试头或示例头到 include 目录。文档、示例和模块许可安装到
`share/eui-neo/modules/plot/`；共享依赖声明仍位于 `share/eui-neo/licenses/`。
源码构建的可执行文件仍输出到框架构建目录（Visual Studio 的 Release 子目录），与共享 assets
的部署约定一致；源文件迁移不改变已有启动命令。

在仓库根目录检查分支边界：

```powershell
git diff --name-status main HEAD
git diff --name-only main HEAD -- . ':(exclude)modules/plot/**'
```

第一条只应出现 `A modules/plot/...`；第二条应无输出。还需检查 `git status --short`，避免遗漏
未提交或未跟踪的模块外文件。主分支后续通用修复应同步进入 plot，而不是在模块内复制核心实现。
