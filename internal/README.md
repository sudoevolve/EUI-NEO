# 内部开发记录

本目录保存维护过程与历史证据，不作为现行 API 文档或功能支持承诺。使用说明从 [docs/README.md](../docs/README.md) 查阅。

| 目录 | 用途 |
| --- | --- |
| [plans/](plans/) | 尚未实施或未验收的方案：软件渲染、科学绘图 |
| [reviews/](reviews/) | 带日期的代码审查与问题分析 |
| [validation/](validation/) | 某次变更的测试环境、结果与局限 |
| [benchmarks/](benchmarks/) | 性能测量方法、对照结果、复现脚本 |
| [benchmarks/data/](benchmarks/data/) | 对应测量的原始数据 |

文件名使用小写英文与连字符，日期使用 `YYYY-MM-DD`。保留记录当时的环境和结论；后续状态通过更新说明或引用新记录补充，不把历史通过项视为当前版本已重新验收。官网只发布 `docs/`，不复制本目录。
